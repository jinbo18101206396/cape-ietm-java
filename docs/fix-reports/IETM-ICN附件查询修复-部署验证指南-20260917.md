## 一、部署步骤

### 方案A：手动重启后端服务（推荐）

1. **停止当前运行的后端服务**
   - 如果是IDE运行：在IDEA中停止运行
   - 如果是命令行运行：找到进程并停止
   ```bash
   # Windows查找Java进程
   jps -l
   # 或者通过端口查找
   netstat -ano | findstr :9999
   # 记录PID后停止
   taskkill /PID <进程ID> /F
   ```

2. **启动后端服务**
   - 在IDEA中：运行 `ietm` 模块的主类（通常是 `*Application.java`）
   - 或命令行：
   ```bash
   cd D:\workspace\IETM\cape-ietm-java\ietm
   mvn spring-boot:run
   ```

3. **确认服务启动成功**
   - 检查控制台日志，确认端口9999监听成功
   - 访问: http://localhost:9999/

## 三、问题排查

### 问题1：仍然报 business_id 错误

**原因**: 可能是旧代码未被替换

**解决**:
1. 确认修改的文件已保存
2. 清理并重新编译:
   ```bash
   mvn clean compile -pl jeecg-module-ietm -am
   ```
3. 完全停止后端进程，重新启动

### 问题2：ICN图片仍然显示占位图

**可能原因**:
1. ICN附件数据本身缺失 - 检查 `ietm_attachment` 表
2. 文件物理路径不存在 - 检查配置项 `accessFile.icnLocation`
3. 文件加密/解密问题 - 查看后端详细日志

**排查SQL**:
```sql
-- 检查某个ICN的附件记录
SELECT * FROM ietm_attachment 
WHERE pid = '<ICN_ID>' 
  AND file_type = 'entity'
ORDER BY create_time ASC;

-- 检查ICN记录
SELECT * FROM ietm_icn_manage 
WHERE icn = 'ICN-ZB1-A-020000-60101-30101-00017-A-001-01';
```

### 问题3：编译后修改未生效

**原因**: IDE可能使用了缓存的class文件

**解决**:
1. IDEA: File → Invalidate Caches → Invalidate and Restart
2. 手动删除target目录:
   ```bash
   rm -rf jeecg-module-ietm/target
   mvn clean compile
   ```

## 📊 测试数据准备

如果您没有合适的测试数据，可以使用以下SQL查找：

```sql
-- 查找包含graphic标签的DM
SELECT id, dm_code, dm_title 
FROM ietm_data_module 
WHERE dm_content LIKE '%<graphic%' 
LIMIT 10;

-- 查找有附件的ICN
SELECT i.id, i.icn, i.sns, COUNT(a.id) as attachment_count
FROM ietm_icn_manage i
LEFT JOIN ietm_attachment a ON a.pid = i.id AND a.file_type = 'entity'
GROUP BY i.id, i.icn, i.sns
HAVING COUNT(a.id) > 0
LIMIT 10;
```

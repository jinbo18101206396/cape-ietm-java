                              问题分析
================================================================================

根本问题
-------
DM8数据库限制: "表中不能同时包含聚集KEY和大字段"

- ietm_icn_manage 表有 CLUSTER 索引（INDEX33558333）
- 无法添加 CLOB 字段存储公式HTML
- 旧系统Oracle/MySQL使用BLOB，新系统DM8受限

尝试的方案
---------
方案A: 删除聚集索引后添加CLOB字段
  - 问题: DM8权限系统阻止所有删除操作
  - 即使SYSDBA也无法授权IETM用户删除索引
  - 根本原因: DM8对SYSDBA权限限制比Oracle更严格

解决方案
-------
方案B: 创建独立的公式表 ietm_icn_formula
  - ✅ 无需修改现有表结构
  - ✅ 无需特殊权限
  - ✅ 对现有ICN功能零影响
  - ✅ 2小时内完成
  - ✅ 可独立回滚

================================================================================
                         技术决策与权衡
================================================================================

为什么选择方案B?
--------------
1. ✅ 技术可行性: 立即可行（无权限问题）
2. ✅ 功能影响: 对现有系统零影响
3. ✅ 设计优雅: 职责分离（公式 vs 图符）
4. ✅ 实施效率: 2小时完成
5. ✅ 回滚简单: 删除表即可
6. ✅ 扩展性: 未来可轻松扩展

为什么用CLOB存储?
-----------------
1. 对标旧系统: Oracle/MySQL都用BLOB
2. 完整性: 保留LaTeX源码(data-latex属性)
3. 事务性: 数据库原子操作
4. 性能: 无磁盘I/O开销（相比附件表）

为什么用独立表?
---------------
1. 绕过DM8限制: 聚集索引与大字段不能共存
2. 职责分离: 公式ICN vs 图符ICN逻辑不同
3. 零影响: 不修改ietm_icn_manage表结构
4. 可回滚: 完全独立的新表

             \"sns\":\"ZB1-A-02-60101\",
             \"rpc\":\"P\",
             \"originator\":\"A001\",
             \"uniqueid\":\"00001\",
             \"variantcode\":\"A\",
             \"securityclassification\":\"01\",
             \"issueno\":\"001\",
             \"secretLevel\":\"1\",
             \"cmnodeid\":\"1234567890\",
             \"filename\":\"formula.png\",
             \"filecontent\":\"<img class=\\\"kfformula\\\"
                               src=\\\"data:image/png;base64,iVBORw0K...\\\"
                               data-latex=\\\"E=mc^2\\\" />\"}"
  }

  响应成功:
  {
    "success": true,
    "message": "公式保存成功",
    "code": 200,
    "result": null

    "success": false,
    "message": "错误信息描述",
    "code": 500,
    "result": null
  }

    "code": 200,
    "result": {
      "formula": "<img class=\"kfformula\"
                   src=\"data:image/png;base64,iVBORw0K...\"
                   data-latex=\"E=mc^2\" />"

  }

  响应成功（普通图符）:
  {
    "success": true,

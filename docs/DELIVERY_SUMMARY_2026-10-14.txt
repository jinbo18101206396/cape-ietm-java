                              实现总结
================================================================================

【背景】
用户需要正确实现Para设计视图的公式保存功能。前置排查发现旧JSP系统使用BLOB存储
模式（而非磁盘文件），存储完整的<img>标签HTML（包含base64图片和LaTeX源码）。

【方案】
对标旧系统实现，采用BLOB存储模式：
  • 保存: 完整的<img class="kfformula".../>标签 → UTF-8编码 → BLOB存储
  • 加载: BLOB读取 → UTF-8解码 → 恢复完整HTML

【关键实现】
1. IetmIcnManage.java          新增 filecontent 字段（byte[]）
2. IetmIcnManageMapper.java    新增 getByIcnWithContent() 方法
3. IetmIcnManageMapper.xml     新增查询 SQL
4. IIetmIcnManageService.java  新增接口方法
5. IetmIcnManageServiceImpl.java 新增实现
6. IetmIcnManageController.java 新增两个端点：
   - POST /ietm/icn/save-formula    (保存公式)
   - POST /ietm/icn/getIcnContent   (加载公式)

================================================================================
                            关键要点总结
================================================================================

【为什么用BLOB?】
  ✓ 旧系统已证实使用BLOB
  ✓ 事务一致性：数据库原子操作
  ✓ 完整性：保留LaTeX源码（data-latex属性）
  ✓ 性能：无磁盘I/O开销

【与普通图符的区别】
  ┌─────────────┬──────────────┬──────────────┐
  │   特征      │    公式ICN   │   普通图符   │
  ├─────────────┼──────────────┼──────────────┤
  │ 存储字段    │ filecontent  │  fileKey     │
  │ 内容        │ 完整HTML     │  文件路径    │
  │ LaTeX源码   │ ✓ 保留       │  ✗ 无       │
  │ 查询方法    │ getByIcnWith │ loadAttach   │
  │             │ Content()    │ ment()       │
  │ 返回字段    │ result.      │  result.dto  │
  │             │ formula      │              │
  └─────────────┴──────────────┴──────────────┘

【完整生命周期】
  前端        : <img class="kfformula" src="data:..." data-latex="..."/>
        ↓ JSON.stringify
  前端JSON    : {"icn":..., "filecontent":"<img...>"}
        ↓ axios POST /ietm/icn/save-formula
  后端        : 接收JSON → 解析FormulaIcnVO
        ↓ UTF-8编码
  字节数组    : byte[] = html.getBytes("UTF-8")
        ↓ MyBatis BLOB处理
  数据库      : ietm_icn_manage.filecontent = BLOB
        ↓ (下次打开设计视图)
  后端        : getByIcnWithContent(icn)
        ↓ 读BLOB → UTF-8解码
  后端JSON    : {"formula":"<img...>"}
        ↓ 返回前端
  前端        : UEditor恢复显示公式
